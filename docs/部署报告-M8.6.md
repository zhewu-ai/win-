## 功能内容（对应 SPEC M8.6）

### 布局三档（720 / 900 明确阈值，替换旧 520/580 迟滞）

- spacious（≥900px）：侧栏 350px 双栏。
- compact（720–899px）：侧栏 280px 双栏，工具栏文字态。
- single（<720px）：单栏，列表与编辑器互斥切换，顶部返回键。

### 工具栏三态（按编辑器实际宽度，而非窗口宽度）

- spacious（≥520px）：完整文字 + 5 色球 + 保存文案 + 分割线。
- compact（360–519px）：色板按钮 + 无文字 + 圆点保存状态。
- minimal（<360px）：仅图标，颜色收入「更多」菜单，隐藏分割线与保存槽。

### 窄窗不裁切（核心修复）

- 根因：`<textarea rows={1}>` 有 ≈20ch 的固有最小内容宽度（默认 cols=20），在 flex 容器里把编辑器顶到 297px，导致 260px 窗口横向裁切；`min-w-0` 无法降低 textarea 的最小内容贡献。
- 修复：checklist 两个 textarea 加 `w-0`（width:0），由 flex 布局实际分配宽度。260px 下实测编辑器 260px、无横向溢出、无水平滚动条。

### 过渡动画

- 工具栏模式切换：`toolbar-item`（toolbar-pop 120ms 淡入）。
- 弹层/菜单：`menu-pop`（120ms 上移 + 缩放）。
- 侧栏折叠/展开：`width + opacity` 150ms 过渡。

## 第二轮修正（侧栏手动 + 工具栏迟滞，2026-08-06）

> 提交：80264a2（fix(m8.6): 侧栏固定350手动折叠 + 工具栏断点20px迟滞，消除拖动时彩色球跳动）
> 背景：用户反馈窗口缩放跨断点时，编辑器右侧彩色球随侧栏自动出现/收起而跳动。

### 改动内容

| 文件 | 改动 |
|---|---|
| `src/hooks/useLayoutMode.ts` | 三档（spacious/compact/single）简化为两档（dual/single，720 阈值），去掉 900 断点 |
| `src/app/(protected)/page.tsx` | 双栏侧栏固定 350px（不再 350/280 两档随 900 断点切换），仅由手动折叠按钮控制并持久化 |
| `src/app/(protected)/archive/page.tsx` | 双栏列表固定 w-80（去掉 288 分支） |
| `src/components/NoteEditor.tsx` | 工具栏断点加 20px 迟滞：进入 spacious ≥520 / compact ≥360，退出 <500 / <340，断点边缘微调不再反复横跳 |

### 设计要点

- **双栏区间（≥720）**：侧栏宽度固定 350px，窗口缩放不再自动改变侧栏，仅手动折叠/展开（localStorage 持久化）。
- **窄窗（<720）**：保留自动单栏（物理上窄窗放不下 280px 侧栏 + 编辑器，属硬约束）。
- **工具栏迟滞**：spacious↔compact 迟滞区（编辑器宽 500–519）、compact↔minimal 迟滞区（340–359），进入用高阈值、退出用低阈值，窗口在断点附近微调时形态稳定不跳。
