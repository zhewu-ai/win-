## 验收步骤与证据清单

### 0. 准备

1. 安装本轮新包（先卸载旧版）。
2. 打开 App，登录生产账号。
3. 准备：一条含 3 张图片的便签、一条待办便签、AE/C4D/浏览器/资源管理器等其它软件窗口。

### 1. QA-M7-F01：置顶能力（本轮重点）

验证点：

1. 主编辑页顶部工具栏应有「窗口置顶」按钮（显示器+图钉图标），悬浮窗里也有。
2. 打开悬浮窗 → **默认自动置顶**，悬浮在其它软件窗口前方。
3. Alt+Tab 切换到其它应用 → 悬浮窗仍停留在最前、不被遮挡。
4. 点悬浮窗「取消窗口置顶」→ 可被其它窗口遮挡；再点「置顶」→ 重新保持最前。
5. 关闭悬浮窗并重新打开 → 置顶状态按上次设置恢复。
6. 若点「极小模式」没反应：现在会弹「打开悬浮窗失败」提示，请把提示内容贴回反馈。

证据要求：

- 录屏：悬浮窗在其它软件（AE/C4D/浏览器/资源管理器）前方保持不遮挡，重点录 **Alt+Tab 切换** 的过程。
- 截图：主编辑页「窗口置顶」按钮可见。
- 录屏：置顶开关开→关→开。
- 若仍置顶失败：把 Windows DevTools 控制台里 `toggle_always_on_top failed:` / `set_always_on_top` 相关报错贴回（现在不静默）。

### 2. QA-M7-F02：极小模式 / 可缩小

验证点：

1. 主编辑页「极小模式（以悬浮窗打开当前便签）」按钮可打开独立悬浮小窗口（无侧边栏）。
2. **主窗口可以直接缩到很小**：拖拽主窗口边缘，应能缩到约 320px 宽（移动端布局，列表/编辑器切换 + 返回按钮），不再卡在 900×600。
3. 悬浮窗可缩到约 260px 宽，工具栏自动换行不溢出，编辑仍可用。
4. 悬浮窗内核心操作可用：编辑、便签/待办切换、图片上传、图片删除、置顶开关、返回主窗口。

证据要求：

- 录屏：主窗口从默认尺寸一路缩到很小，展示无卡死、布局正常。
- 截图：约 320px 主窗口 / 260px 悬浮窗各一张。
- 截图：主编辑页「极小模式」入口。

### 3. QA-M7-F03：图片单独删除

验证点（主编辑页与悬浮极小页各做一遍）：

1. 上传 3 张图片到同一条便签。
2. 删除第 2 张 → 第 1、3 张保留，第 2 张立即消失。
3. 刷新页面 → 第 2 张仍不存在。
4. 预览大图内也可删除，删除后立即消失。
5. 删除按钮无需悬停即始终可见。

证据要求：

- 录屏或接口日志：上传 3 张 → 删除其中 1 张 → 刷新后仍删除。
- 截图：删除按钮未悬停可见。
- 若删除失败：贴弹窗提示（带 `HTTP xxx` 状态码）和 DevTools 网络面板。
