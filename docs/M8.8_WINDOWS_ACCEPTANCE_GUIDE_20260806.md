## 本轮验收重点

### 1. 断网冷启动不显示错误页（P0，桌面壳专项）

前置：先**在线**打开一次 App，让 Service Worker 安装并缓存 App Shell；然后断开网络。

验证点：

1. **在线首次打开**：登录后正常进入便签列表（SW 已注册，可 F12 → Application → Service Workers 确认 `notes.hello-mylife.online` 有 active worker）。
2. **断网冷启动**（桌面壳）：关闭 App → 断开网络 → 重新打开 App → **不显示 WebView 错误页**，而是「当前离线 / 正在使用本地缓存 / 重试连接」fallback 页（或直接显示缓存 App）。
3. 点「重试连接」→ 联网后自动跳转线上 App。
4. **浏览器断网刷新**（Web 端专项）：Chrome DevTools Network → Offline → 刷新 `https://notes.hello-mylife.online/` → 仍出 App（列表为空或本地缓存），OfflineBar 显示「离线模式」。

证据要求：断网冷启动 + 联网重试各录一段（或截图 fallback 页）。

### 2. 离线新建/编辑/删除 + 关闭重开不丢（P0，核心）

前置：登录后正常加载列表 → DevTools 切 Offline（或桌面壳断开网络）。

验证点：

1. 侧边栏「新建」→ 普通便签，输入标题与正文 → 顶部保存文案显示**「已保存到本地」**（不得显示「已同步」）；顶部出现**「离线模式」**提示条。
2. 新建待办便签 → 添加 3 条 → 勾选 1 条 → 保存文案「已保存到本地」。
3. 打开一条既有便签 → 修改正文 →「已保存到本地」。
4. **关闭重开**：完全关闭 App / 浏览器标签页 → 断网状态下重新打开 → 上述 3 条新建/修改内容**全部仍在**（含待办勾选状态）。
5. 删除一条既有便签 → 从列表消失。
6. 尝试上传图片 → 上传按钮**禁用**，悬停提示「离线模式下暂不支持上传图片」。

证据要求：离线新建普通 + 待办（含勾选）、关闭重开后内容仍在，各截图/录屏。

### 3. 联网自动同步（P0，核心）

前置：保持上述离线状态下新建/编辑的内容不清理。

验证点：

1. 恢复网络 → OfflineBar 消失 → 保存文案经「同步中 / 等待同步」过渡。
2. 刷新页面（或切换到另一台设备浏览器）→ 服务器端可见离线新建的普通便签、待办便签（**勾选状态保留**）、离线修改内容已更新、离线删除的便签已消失。
3. 冲突口径：离线编辑的便签，联网后以**本机最后编辑**为准，不被服务器旧内容覆盖。

证据要求：恢复网络后自动同步全流程录屏 + 刷新后服务器可见的截图。

### 4. 浮窗便签（P1）

1. 桌面壳打开一条便签为浮窗 → 断网 → 浮窗仍显示该便签内容（缓存回填）。
2. 浮窗内离线编辑 → 关闭重开浮窗 → 内容仍在。

证据要求：浮窗离线打开 + 关闭重开截图。

### 5. 离线登录（P1）

1. 浏览器打开 `https://notes.hello-mylife.online/login` 断网（或从未登录 + 断网）→ 登录页提示「离线状态无法登录，联网后重试」。
2. 联网后正常登录。

证据要求：断网登录页截图。
