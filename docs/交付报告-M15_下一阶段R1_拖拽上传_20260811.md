## 三、验证

### 3.1 dev 浏览器（localhost:3000，admin）

**AI 导入拖拽**（`/calendar` 展开右栏）：
- 拖入 PNG → drop zone 高亮 `border-primary/60 bg-primary/5`、按钮文案变"松开以上传给 AI" ✓
- 松开 PNG → 触发 `/api/calendar-imports/parse`（fetch 计数 1）✓
- 拖入 PDF → "当前仅支持 Excel 和图片"，不触发 parse ✓
- 拖入 2 个文件 → "一次仅支持导入 1 个文件"，不触发 parse ✓
- 拖入纯文本 → 放行，无提示、无请求 ✓

**便签图片拖拽/粘贴**（新建便签）：
- 粘贴 PNG → `POST /api/notes/:id/attachments` 1 次，附件图出现在附件区 ✓
- 拖入 .txt → alert "仅支持上传图片"，不上传 ✓
- 粘贴 PDF 文件 → alert "仅支持上传图片"，不上传 ✓
- 粘贴纯文本 → 不拦截（无 alert、无上传）✓
- 模拟离线粘贴 → alert "离线模式下暂不支持上传图片"，不上传 ✓

**320px 窄窗**：drop zone 在右栏抽屉内实测宽 247px（抽屉 272px），无 zone 溢出（body 溢出 413px 来自日历月视图网格，属既有现象，与 drop zone 无关——抽屉为 fixed 不占文档流）✓

- 便签图片非图片提示用 `alert`（与既有 hidden 上传入口一致），后续若引入统一 toast 可替换。
