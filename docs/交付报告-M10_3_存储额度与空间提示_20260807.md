## 3. schema 变更说明

```prisma
model User {
  id                String   @id @default(cuid())
  username          String   @unique
  passwordHash      String
  displayName       String?
  avatarColor       String?
  storageQuotaBytes Int      @default(10485760)  // 新增：默认 10 MB
  storageUsedBytes  Int      @default(0)         // 新增：已用空间（后端维护，前端只读）
  // …（createdAt / updatedAt / notes / attachments 不变）
}
```

- 两列均有默认值，`db push` 后老用户 `admin` 自动获得 `quota=10485760, used=0`。
- `storageUsedBytes` 仅由后端统计函数更新，前端不能直接写（`/api/auth/me` 白名单不含该字段）。
- 额度口径（SPEC §2.2）：文本 = `Buffer.byteLength`（title/content/checklistItems/checklistGroups）；附件 = `Attachment.size`；回收站内容计入，仅永久删除释放。

## 12. 已知非本轮问题

- **HomePage hydration warning**：`src/app/(protected)/page.tsx` 的 `sidebarCollapsed` 用 localStorage 初始化（服务端 `false`、客户端可能 `true`），触发 `div` 结构 hydration 不匹配警告。**为既有问题**（M8.9 引入，`git log` 确认不在本轮改动范围），React 自动以客户端内容恢复，不影响功能，建议后续单独修复。

## 13. 回退方案

若出现历史数据不可见、附件异常、保存异常：

```bash
# 1) 停服务
export XDG_RUNTIME_DIR="/run/user/$(id -u)"
systemctl --user stop sticky-notes.service

# 2) 恢复 M10.3 前数据库备份
cp /home/ubuntu/backups/prod_M10_3_20260807_034340.db \
   /home/ubuntu/projects/sticky-notes/data/prod.db

# 3) 校验
sqlite3 /home/ubuntu/projects/sticky-notes/data/prod.db "PRAGMA integrity_check;"

# 4) 回退代码（git checkout 上轮 commit 后 rsync src/ --delete + prisma/schema.prisma）
# 5) 重新 build + 重启服务
npm run build
systemctl --user restart sticky-notes.service

# 6) 复查：admin 可登录 / Note 26 / Attachment 1 / 旧图片可打开
```

回退后两列随 schema 回退被 `db push` 移除，历史便签/附件不受影响（均为新增列）。
