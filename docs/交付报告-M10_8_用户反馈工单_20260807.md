# PinNote M10.8 补交：用户反馈工单（用户提交 + 管理员后台）

日期：2026-08-07

## 1. 结论摘要

M10.8 主体（修改密码/多选删除/自定义头像/更新时间准确性）已上线。本轮按 `SPEC_M10_8` §9 补齐遗漏的**用户反馈工单**功能：普通用户账号菜单提交反馈，管理员在 `/admin/feedback` 后台集中查看、筛选、标记状态、填写备注。本地与生产验收全部通过并已上线。

- 用户侧：账号菜单「反馈问题」→ 弹窗（类型 问题/建议/其他 + 标题 + 详细描述 + 可折叠环境信息）→ `POST /api/feedback` → 成功文案「反馈已提交，感谢你帮助改进 PinNote。」
- 管理员侧：账号菜单「用户反馈」→ `/admin/feedback` 后台页（未处理数、状态/类型筛选、状态流转 open/reviewing/resolved/closed、管理员备注）。
- 限制：单用户 1 分钟最多 3 条（429 RATE_LIMITED）；标题 1-80、描述 1-2000；类型仅 bug/feature/other；disabled 用户不可提交；反馈附件本轮不做。

## 3. 数据模型

```prisma
model FeedbackTicket {
  id         String   @id @default(cuid())
  userId     String
  type       String
  title      String
  content    String
  status     String   @default("open")
  pageUrl    String?
  userAgent  String?
  appVersion String?
  adminNote  String?
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt

  user User @relation(fields: [userId], references: [id])

  @@index([userId])
  @@index([status])
  @@index([createdAt])
}
```

`User` 增加 `feedbackTickets FeedbackTicket[]`。`prisma db push` 非破坏性新建表，不触碰既有表。

## 4. API

### `POST /api/feedback`（用户提交）
请求 `{ type, title, content, pageUrl? }`；`userAgent` 服务端从 header 取，`pageUrl` 客户端传当前路径。

| 场景 | HTTP | error |
|---|---:|---|
| 未登录 | 401 | `UNAUTHORIZED` |
| disabled 用户 | 403 | `ACCOUNT_DISABLED` |
| 1 分钟超 3 条 | 429 | `RATE_LIMITED` |
| type 非 bug/feature/other | 400 | `INVALID_FEEDBACK_TYPE` |
| 标题为空 | 400 | `TITLE_REQUIRED` |
| 标题 >80 | 400 | `TITLE_TOO_LONG` |
| 描述为空 | 400 | `CONTENT_REQUIRED` |
| 描述 >2000 | 400 | `CONTENT_TOO_LONG` |
| 请求体非法 | 400 | `INVALID_REQUEST` |

成功 `{ ok: true, ticket: { id } }`。限流复用 `src/lib/rateLimit`（`feedback:user:<id>`, 3, 60_000）。

### `GET /api/admin/feedback`（管理员）
`requireAdmin()`（未登录 401 / disabled 403 / 非 admin 403 FORBIDDEN）。`?status=` / `?type=` 可选筛选。返回 `{ ok, tickets[], openCount }`（openCount = status open 未处理数；ticket 含用户 username/email/displayName）。

### `PATCH /api/admin/feedback/:id`（管理员）
`requireAdmin()`。请求 `{ status?, adminNote? }`。

| 场景 | HTTP | error |
|---|---:|---|
| status 非法 | 400 | `INVALID_STATUS` |
| adminNote 非 string/null 或 >2000 | 400 | `INVALID_ADMIN_NOTE` / `ADMIN_NOTE_TOO_LONG` |
| 空 body | 400 | `NO_FIELDS_TO_UPDATE` |
| id 不存在 | 404 | `TICKET_NOT_FOUND` |

空备注清空为 null；返回更新后 ticket。

## 5. 界面

### 反馈弹窗（普通用户）
- 账号菜单「反馈问题」打开；类型三段选择（问题/建议/其他）、标题、详细描述（带字数计数）、「展开环境信息」折叠块（显示当前页面路径）。
- 前端校验：标题空→「请输入标题」、>80、描述空→「请填写详细描述」、>2000；RATE_LIMITED→「提交太频繁，请 1 分钟后再试」。
- 成功→「反馈已提交，感谢你帮助改进 PinNote。」+「完成」关闭。Escape/点遮罩可关闭。

### 管理面板 `/admin/feedback`
- 顶栏「用户反馈」+「X 条未处理」徽标。
- 状态筛选（全部/未处理/处理中/已解决/已关闭）+ 类型筛选（全部类型/问题/建议/其他）。
- 每条反馈：用户头像/昵称/邮箱、类型与状态徽标、提交时间、页面路径、标题与描述、UA、管理员备注输入框 + 保存。
- 操作按钮：处理中/已解决/已关闭（当前状态高亮禁用）。保存备注后 reload 持久化。

## 9. 风险与后续建议

1. 限流为单进程内存级（复用既有 `rateLimit`），多实例部署时需改共享存储；当前生产为单 systemd 服务进程，满足口径。
2. 反馈工单当前不做附件上传、不做用户侧进度可见、不做邮件通知（SPEC 明确排除）；如需可在后续 M 轮次补充。
3. 管理员重置密码后「请尽快修改密码」的 `mustChangePassword` 提示（SPEC §5.1.1 推荐方案）本轮仍未做，建议排入下一轮。
4. 头像服务端缩放/压缩（SPEC §7.3，当前仅校验不缩放）同样留待后续。
