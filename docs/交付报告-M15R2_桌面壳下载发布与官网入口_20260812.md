### 4.1 CI 排错记录（两处，均已在 workflow 修复）

1. **npm 吞掉 `--target`**（run 31605872256 失败）：`npm run tauri build --target universal-apple-darwin` 不带 `--` 时，npm 把自己认识的 `--target` 吃掉，tauri 收到 `universal-apple-darwin` 作为非法位置参数。修复：`npm run tauri build -- ${{ matrix.target }}`（加 `--` 分隔符）。
2. **mac universal 产物路径与 upload 不匹配**（run 31606854429 失败）：`--target universal-apple-darwin` 的产物在 `target/universal-apple-darwin/release/bundle/`，而 upload 硬编码 `target/release/bundle/`，找不到文件触发 `if-no-files-found: error`。Windows 构建成功、mac 上传失败 → release 被跳过。修复：矩阵加 `bundle-path` 字段，upload 用 `${{ matrix.bundle-path }}`。

第三次重跑（run 31611681729）**completed success**，release 正常创建，双平台资产齐全。

## 六、风险与后续建议

- **Mac 包未签名/未公证**：首次打开需系统设置放行；已明确标注「内测包」。后续可做 Developer ID 签名 + 公证以去除警告。
- **直链随版本漂移**：`downloads.ts` 两个直链 URL 必须随每次桌面壳发版同步更新（文件头已写明规则）。后续可选方案：改成链接 `/releases/latest` 页面彻底免维护。
- **Universal 包体积**：约 100MB+，属预期。
- **触发路径收窄**：web-only 改动不再触发桌面壳重建，节省 CI 资源；桌面壳依赖仅 `src-tauri/**` + `shell-static/**`。
