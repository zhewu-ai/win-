## 四、开放全部用户时的改动清单（执行动作项，非阻塞）

按用户决定「工作日历开放、AI 完全开放、不限频」，开放时执行：

1. **API 放行**：`work-projects`、`work-schedule-items`、`calendar-adjustments/preview`、`calendar-adjustments/apply` 的 `requireAdmin()` → 改为「已登录即通过」（`requireUser` 或等价）。
2. **前端入口放行**：`NoteList.tsx` `showCalendarGroup = Boolean(isAdmin && onOpenCalendar)` 去掉 `isAdmin`。
3. **`/calendar` 独立页**：解除普通用户的 403/重定向，改为正常渲染。
4. **数据隔离确认**：`WorkProject.userId` + `isProjectOwnedBy(当前用户id)` 已按用户隔离，普通用户各自管理自己的项目/排期，无跨用户数据暴露。已核对代码。
5. **空状态引导**：普通用户首次进入工作日历无项目，建议展示「新建项目」引导（非阻塞，可后续补）。
6. **AI 成本提示**：AI 完全开放且不限频 = 所有普通用户可消耗硅基流动配额，成本随用量增长。已按用户决策记录，建议运营侧关注用量（`usage.durationMs` / token 已打日志）。
