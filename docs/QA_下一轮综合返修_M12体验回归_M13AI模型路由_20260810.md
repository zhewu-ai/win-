## 三、M13 AI 排期导入：单入口 + 自动模型路由

### 3.1 上传入口合并

当前入口：

```text
[ 上传图片 ] [ 上传 Excel ]
```

建议改为一个入口：

```text
[ 上传给 AI ]
```

或：

```text
[ 上传排期文件 ]
```

理由：

- 用户不需要先判断文件类型。
- Excel 不可能被识别成图片，图片也不应该走 Excel 解析。
- 后端做文件类型路由即可，前端少一个按钮，界面更轻。

验收：

- 前端不再并列显示“上传图片 / 上传 Excel”两个按钮。
- 上传 Excel 自动进入 Excel 导入。
- 上传图片自动进入图片导入。
- PDF / 未知文件类型直接拒绝，提示“当前仅支持图片和 Excel”。

### 3.2 后端自动判断文件类型

后端同时检查扩展名和 MIME：

- `.xlsx` / `.xls` / `.csv` 或 Excel MIME：走 Excel 解析链路。
- `.png` / `.jpg` / `.jpeg` / `.webp` 或 image MIME：走图片识别链路。
- `.pdf`、未知扩展名、未知 MIME：拒绝，不进入 AI 调用。

接口保持一个即可：

```http
POST /api/calendar-imports/parse
Content-Type: multipart/form-data

file=<用户上传文件>
```

返回应包含：

```json
{
  "kind": "excel",
  "model": "Qwen/Qwen3-30B-A3B-Instruct-2507",
  "draft": {},
  "usage": {}
}
```

### 3.3 按文件类型拆分模型

根据模型测试报告：

- 当前 `Qwen/Qwen3.5-9B` 处理 Excel 约 61.9s 到 66.4s，容易触发 60s 超时。
- `Qwen/Qwen3-30B-A3B-Instruct-2507` 处理同一 Excel 转文本输入约 27.5s，更适合作 Excel 默认模型。
- 图片需要视觉理解，推荐 `Qwen/Qwen3-VL-32B-Instruct`，图片实测约 36.5s，质量更稳。
- `Qwen/Qwen3-VL-30B-A3B-Instruct` 虽快但漏识别明显，不建议默认。

配置要求：

```env
SILICONFLOW_EXCEL_MODEL="Qwen/Qwen3-30B-A3B-Instruct-2507"
SILICONFLOW_IMAGE_MODEL="Qwen/Qwen3-VL-32B-Instruct"
SILICONFLOW_MODEL="Qwen/Qwen3.5-9B"
```

选择逻辑：

- `kind === "excel"`：优先使用 `SILICONFLOW_EXCEL_MODEL`。
- `kind === "image"`：优先使用 `SILICONFLOW_IMAGE_MODEL`。
- 未配置专用模型时，才回退到 `SILICONFLOW_MODEL`。

### 3.4 兼容风险

不能对所有 Qwen3 模型一刀切传：

```ts
enable_thinking: false
```

原因：

- `Qwen3-VL-*-Instruct` 在硅基流动接口上不支持该参数。
- 只改模型名、不改参数能力判断，会导致图片模型调用失败。

要求：

- 按模型能力配置请求参数。
- `Qwen/Qwen3.5-9B` 可传 `enable_thinking: false`。
- `Qwen3-VL-*-Instruct` 不传 `enable_thinking`。
