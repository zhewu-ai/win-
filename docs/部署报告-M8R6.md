## 剩余风险

1. **无 Git 历史**：服务器上代码仍无 `.git` 目录，更新依赖 rsync。建议后续在服务器初始化 Git 仓库。
2. **视觉项需 Windows 真机最终确认**：F01/F02 已在 320/1280px 浏览器视口以 DOM 几何测量验证（底部栏不透明、列表可滚、今天分组置顶、日期显示），Windows 主窗同宽度下建议按验收指引再走一遍。
3. **「日期没加」的说明**：日期功能代码已确认在生产生效；刚编辑过的便签按规则显示「刚刚 / x分钟前」，满 1 小时起显示「今天 14:30 / 昨天 18:20 / 07-01 14:30」等具体时间。若希望在刚编辑后也直接显示时钟时间，可后续调整 `lib/format-time.ts` 阈值。
