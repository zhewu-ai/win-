日期：2026-08-07

## 1. 结论摘要

本轮完成三块：

1. **登录入口收口**（已满足，未改代码）：未登录访问首页重定向到登录页、已登录访问登录页回主页、退出登录清除会话、未登录访问 API 返回 401。四项全部验证通过。
2. **基础身份展示**：`User` 新增 `displayName` / `avatarColor` 可选字段；`GET /api/auth/me` 返回新字段；新增 `PATCH /api/auth/me`，白名单仅允许改 `displayName`（≤40 字，空则置 null）与 `avatarColor`（必须 ∈ 预设 5 色），无法触碰 `username` / `passwordHash`；左下角账号菜单显示首字圆形文字头像 + 昵称/username + 修改昵称表单。
3. **图片入口降级**：主工具栏图片按钮移除，**「置顶便签」图标按钮放到原图片位置**；更多菜单移除「置顶便签」，新增「添加图片」（隐藏 input 常驻 DOM，经菜单项触发文件选择）；「窗口置顶」（Tauri）保持原位。

生产已部署并回归通过。数据零变化（User 1 / Note 26 / Attachment 1）。

## 3. schema 变更说明

```prisma
model User {
  id           String   @id @default(cuid())
  username     String   @unique
  passwordHash String
  displayName  String?   // 新增：昵称，空则 null，前端 fallback 到 username
  avatarColor  String?   // 新增：预设 5 色之一，仅后端校验
  // …（createdAt / updatedAt / notes / attachments 不变）
}
```

- `displayName` / `avatarColor` 均为可空列，缺省为 `NULL`，**不影响历史行与登录**。
- 两列仅由 `PATCH /api/auth/me` 写入，`username` / `passwordHash` 不在白名单内。

## 13. 已知非本轮问题

- **HomePage hydration warning**：`src/app/(protected)/page.tsx` 的 `sidebarCollapsed` 用 localStorage 初始化（服务端 `false`、客户端可能 `true`），触发 `div` 结构 hydration 不匹配警告。**为既有问题**（M8.9 侧边栏自动收起引入，`git log` 确认未在本轮改动范围内），React 自动以客户端内容恢复，不影响功能。建议后续单独修复（读 localStorage 前置到首帧渲染或抑制该警告）。

## 14. 回退方案

若出现历史数据不可见、登录阻塞、附件不可用等问题：

```bash
# 1) 停服务
export XDG_RUNTIME_DIR="/run/user/$(id -u)"
systemctl --user stop sticky-notes.service

# 2) 恢复 M10.2 前数据库备份
cp /home/ubuntu/backups/prod_M10_2_20260807_022815.db \
   /home/ubuntu/projects/sticky-notes/data/prod.db

# 3) 校验
sqlite3 /home/ubuntu/projects/sticky-notes/data/prod.db "PRAGMA integrity_check;"

# 4) 回退代码（git checkout 上轮 commit 后 rsync src/ + prisma/schema.prisma）
# 5) 重新 build + 重启服务
npm run build
systemctl --user restart sticky-notes.service

# 6) 复查
#   - admin 可登录
#   - Note 数量恢复 26、Attachment 数量恢复 1
#   - 旧图片可打开
```
