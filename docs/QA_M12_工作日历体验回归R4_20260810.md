# QA M12：工作日历体验回归 R4

日期：2026-08-10

状态：技术部已返修（2026-08-10）

## 一、结论

R3 返修后，部分体验在技术上完成了，但实际使用下来仍有新的问题。R4 不扩新功能，只做体验回归：

1. 便签/待办最小模式顶部工具栏先恢复到上一版稳定状态。
2. 月视图日期格不要单击就跳到日视图，改为单击选中、双击进入日视图。
3. 日视图下方区域需要重新设计，解决空荡、不美观的问题。

## 二、返修项

### 2.1 便签/待办最小模式顶部工具栏先恢复

当前体验：

- R3 做了便签/待办窄宽专注模式。
- 但实际体验后，顶部仍然有一条横栏，占用了空间。
- 它既没有完全释放内容区，又改变了原来熟悉的工具栏体验。
- 用户感觉不如恢复到之前稳定版本。

要求：

- 先把便签/待办最小宽度下的顶部工具栏恢复到上一版稳定状态。
- 本轮不要继续强行做“半隐藏”的顶部栏。
- 后续如果要重新做便签/待办窄宽专注模式，应重新设计完整方案，而不是只隐藏部分按钮但仍保留一条占位横栏。

验收：

- 便签最小宽度下，顶部工具栏回到用户熟悉的上一版表现。
- 待办最小宽度下，顶部工具栏回到用户熟悉的上一版表现。
- 保存状态、返回、颜色、刷新、置顶、图片、归档、删除等入口仍可访问。
- 正常宽度下工具栏不退化。

### 2.2 月视图日期格改为单击选中、双击进入日视图

当前体验：

- 月视图里单击某一天会直接跳到日视图。
- 用户很多时候只是想在月视图里点一下某天看状态，但被直接带走。
- 这很容易误触，打断浏览整个月排期的节奏。

要求：

- 月视图日期格行为改为：
  - 单击：只选中/高亮当天，不切换视图。
  - 双击：进入该日期的日视图。
- 点击排期条目仍应打开排期详情，不要被日期格单击逻辑影响。
- 如果技术部认为双击在触控板或移动端不够理想，可以给等价方案：
  - 单击选中日期后，出现“查看日程”入口。
  - 或在选中态中提供明确进入日视图按钮。

验收：

- 月视图单击日期格，不进入日视图。
- 月视图双击日期格，进入对应日期日视图。
- 点击排期条目仍能查看/编辑排期。
- 320px/390px 下不因误触频繁跳转。

### 2.3 日视图下方区域重新设计

当前体验：

- 日视图下方显得很空。
- 当天排期或便签不多时，页面下半部分空荡，不美观。
- 视觉上像只完成了结构，没有完成日视图的布局整理。

要求：

- 技术部重新设计日视图下方区域。
- 内容少时，不要出现大片无意义空白。
- 内容多时，仍要层级清楚、方便扫描。
- 可以考虑：
  - 当天摘要区。
  - 排期和便签分区。
  - 空状态占位。
  - 时间线式布局。
  - 与月/周视图统一的卡片尺度。
- 不要加大段解释文案。
- 不要做营销式空态。

验收：

- 选中排期很少的日期，日视图下方不空荡。
- 选中排期较多的日期，日视图仍清晰可扫。
- 便签链接层开启/关闭时布局都成立。
- 320px/390px 下不重叠、不溢出、不出现大块尴尬空白。

## 三、执行建议

1. 先回退便签/待办最小模式顶部工具栏到上一版稳定体验。
2. 再调整月视图日期格交互，避免单击误跳转。
3. 最后重新设计日视图下方区域。
