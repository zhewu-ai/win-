## 一、本期范围

内测期运营 + 新手引导四项功能，全部人工可控、可审计：

1. **归档/回收站批量操作**：M10.9 式横向三点入口进入多选，批量取消归档 / 恢复 / 永久删除；永久删除为双层确认（弹窗确认 + 输入 `DELETE` 二次确认）。
2. **管理员手动公告栏**：管理员手写草稿 → 发布 → 用户登录弹窗展示一次（已读不再弹），管理员后台可看已读名单与阅读率统计。**无任何 AI 自动生成/发布。**
3. **管理员删除废用户**：仅限 `disabled` + 非 admin + 非本人 + 无业务数据的用户可硬删，双层确认（输入邮箱或 `DELETE`）。
4. **新用户示例便签**：注册时自动生成 3 条示例便签（`Note.isSample` 标记），占用存储额度，老用户不补发。

## 二、实现说明

### 数据层（`prisma/schema.prisma`，+34 行）
- `Announcement`：id/title/content/version/status（draft/published/archived）/publishedAt/createdById/createdAt/updatedAt。
- `AnnouncementRead`：announcementId+userId，`@@unique([announcementId, userId])` 保证一人一条已读记录。
- `Note.isSample Boolean @default(false)`：示例便签标记，删除不影响正常数据。

### 公告流
- 管理员：`/api/admin/announcements`（增改查）+ `/publish` + `/archive`，草稿可编辑，发布后可归档（不可重发）。
- 用户：`/api/announcements/latest` 拉取已发布公告，`AnnouncementModal` 未读时弹窗一次，关闭/查看即写已读；`/api/announcements/read` 落库。
- 后台阅读统计：应看数 = 当前活跃用户数，已读数 + 阅读率百分比 + 已读用户名单（昵称/邮箱 + 阅读时间）。

### 批量操作（归档/回收站）
- 新路由：`bulk-unarchive`、`bulk-restore`、`bulk-permanent-delete`，统一走 `src/lib/bulk.ts`（去重、上限 100 条、格式校验）。
- `src/lib/permanent-delete.ts`：`hardDeleteNotes` 仅删 `deletedAt: { not: null }` 的便签，连带附件记录 + 文件/目录 + 存储额度释放，事务内完成。
- 双层确认：弹窗确认 → 输入 `DELETE`（永久删除不可恢复）→ 确认后提交。

### 删除废用户（`/api/admin/users/[id]` DELETE）
- 前置校验链：非本人 → 存在 → 非 admin → 必须 `disabled` → 无业务数据（notes/attachments/feedback/announcements/announcementReads 任一存在则 409 拒绝，保留禁用路径）。
- 仅清理未使用的邀请码关系 + 重置令牌后硬删，绝不触碰真实便签数据。

### 示例便签（`src/lib/sample-notes.ts` + 注册路由）
- 注册事务内生成 3 条示例便签（文本 ×2 + 待办 ×1），返回所占存储字节数，`storageUsedBytes` 累计入额度。
- 修复：注册接口响应原先硬编码 `storageUsedBytes: 0`，现返回真实字节数（1048），与 DB 一致。
