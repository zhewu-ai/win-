## 3. 功能一：站内用户化下载页 `/download`

### 3.1 页面结构（`src/app/download/page.tsx`）
- 顶部品牌区：图标 + 「PinNote 桌面版」标题 + 「Windows 桌面应用」副标题。
- 一句话介绍：把重要便签固定在电脑桌面，随时记录待办、备忘和临时想法。网页端和桌面端使用同一账号，数据自动同步。
- 4 个功能点卡片：桌面置顶 / 同步数据 / 待办和备忘 / 离线保护（各配 heroicons 风格图标）。
- 主按钮「下载 Windows 安装包」→ 安装包直链（`DESKTOP_WINDOWS_INSTALLER_URL`，v0.1.0 x64 setup），`target="_blank"`。
- 次链接「查看所有版本」→ GitHub Release 列表页（`DESKTOP_APP_DOWNLOAD_URL`），`target="_blank"`。
- 底部说明：适用于 Windows 10/11。安装后使用你的 PinNote 账号登录。
- 「近期更新」折叠区：5 条产品化更新文案（邀请制注册、存储额度与头像、多选删除与回收站、用户反馈、查看不打乱排序）。
- 页脚居中「PinNote」。

### 3.2 干净口径（QA §4.1 / §6.2）
页面正文与 HTML head 均不含：`全平台便签`、`V0.1.1`、`自动构建`/`构建流水`/`GitHub Actions`、`加载线上`/`URL` 技术描述、`demo`/`test`/`internal` 等字样。
> 补充发现：初版生产 HTML head 中的 `全平台便签` 来自全局 `src/app/layout.tsx` 的 `<meta name="description">`（「PinNote 全平台便签 Web MVP」），不可见但污染元信息。已为 `/download` 增加每页 `metadata`（title=PinNote 桌面版、description=产品介绍）覆盖，head 完全干净。

### 3.3 入口改为内部链接
账号菜单「下载桌面版」由 `href={DESKTOP_APP_DOWNLOAD_URL}`（外链新标签）改为 `Link href={DESKTOP_APP_DOWNLOAD_PAGE_URL}`（`/download`，同标签站内跳转）。展示规则不变：桌面浏览器网页显示（`hidden md:flex`）、手机端隐藏、Windows Tauri 内不渲染。
