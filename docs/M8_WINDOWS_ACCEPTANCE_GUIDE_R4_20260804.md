## 本轮验收重点（第 4 批）

### 1. F01：窄窗编辑态顶部空壳已释放（P0）

验证点：

1. 主窗口缩到约 320px 宽，打开一条便签进入编辑态。
2. 顶部**没有**一条空白厚栏——直接就是编辑器工具栏（返回 / 待办切换 / 颜色 / 置顶 / 归档 / 删除）。
3. 相比上一版，编辑区垂直空间明显变大。
4. 退回列表态，顶部搜索栏正常显示。
5. 左下角新建/账户迷你工具条仍可用。

证据要求：

- 截图：320px 编辑态（顶部无空白栏）+ 320px 列表态（搜索栏存在）。

### 2. F02：小标题线-字-线居中（P1）

验证点：

1. 待办便签中插入两个小标题，分别输入 C4D、AE。
2. 视觉上是 `── C4D ──` 样式：左右各一条细线，文字居中，文字与左右线条在**同一水平中心线**。
3. 小标题行高度适中，不顶天不挤成普通文本。
4. 小标题仍可编辑、删除、拖拽排序，无勾选圆圈。
5. 输入一条 30 字以上的超长小标题，320px 窗口下自动换行、不溢出、不横向滚动。

证据要求：

- 截图：含 C4D / AE 两个小标题的便签，确认居中与对齐。
- 截图：超长小标题在 320px 下换行不溢出。

### 3. F03：时间戳作为底部元信息（P2）

验证点：

1. 新建空便签或只输入几行短文本：时间戳「最后编辑于 …」**贴近编辑区底部**（不是悬在内容中间）。
2. 输入几十行长文本：时间戳位于内容结束**之后**，滚动到底部才看到。
3. 320px 小窗口下时间戳不占用顶部空间、不遮挡正文。

证据要求：

- 截图：短文本便签（时间戳贴底）。
- 截图：长文本便签（时间戳在内容之后）。
