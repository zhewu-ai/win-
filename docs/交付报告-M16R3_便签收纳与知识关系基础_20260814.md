## 一、结论

便签收纳与知识关系基础完成：**P0 单层文件夹**（NoteFolder + Note.folderId，全部/未分组视图、新建/重命名/软删、侧栏筛选、新建自动归属）、**P0 便签归属编辑**（编辑器更多菜单「移动到文件夹」、离线 folderId 同步）、**P1 标签**（NoteTag/NoteTagBinding 关系表，正文 `#标签` 自动识别 + 手动添加，自动/手动不互删，侧栏标签折叠区筛选，文件夹+标签组合筛选）、**P1 反向链接**（NoteLinkEdge，正文 `[[note:id|标题]]` 保存时重算出链，便签底部「被引用 N 次」可展开跳转，删除隐藏/归档标灰）。Web 侧验证全绿，桌面壳 macOS 待实机复核。

## 五、已知限制（SPEC 风险项落地）

1. **标签离线筛选不支持**：离线回填仅按文件夹本地过滤；标签筛选需在线（无 tag id→名映射）。已在代码注释文档化。
2. **restore/duplicate 等未 include tagBindings 的路由**返回 `tags:[]`，前端 refetch 补全，无数据丢失。
3. **旧便签反链懒重建**：旧便签在下次编辑保存前无边；不做全量重建（v1 依赖懒重建，符合 SPEC）。
4. **0 绑定标签行保留**：GET /api/note-tags 只出现 count>0 的标签；0 绑定标签行不自动删（下次含 `#name` 正文保存会重建 auto 绑定）。
5. **多级目录/协作/关系图/AI 问答不做**（SPEC 明确范围外）。
