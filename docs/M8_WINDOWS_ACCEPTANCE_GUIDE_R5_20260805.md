## 本轮验收重点（第 5 批）

### 1. F01：新建/账号在侧边栏底部，顶部不再有全局栏（P1）

验证点：

1. 宽屏下页面顶部**没有**一条全局工具栏——只有左侧侧边栏 + 右侧编辑区。
2. 侧边栏底部有「新建」按钮和「我」账号入口。
3. 点击「我」弹出向上菜单：归档 / 回收站 / 退出登录。
4. 搜索框在侧边栏顶部。
5. 窄窗口下（320px）新建/账号仍可用、不遮挡列表最后一条。

证据要求：

- 截图：宽屏（侧栏底部 新建+账号，无顶栏）。
- 截图：320px 窄窗列表态。

### 2. F02：编辑器工具栏恒单行（P1）

验证点：

1. 打开一条便签，把窗口缩到 260-320px，编辑器顶部工具栏**仍是一行**。
2. 工具栏可见：返回、便签/待办切换、颜色、图片、⋯。
3. 点击「⋯」弹出：置顶便签、归档、删除。
4. 删除按钮**不会**自己掉到第二行。
5. 工具栏高度稳定，不随窗口宽度突然变成两行。

证据要求：

- 截图：260px 编辑器工具栏单行。
- 截图：「⋯」更多菜单展开。

### 3. F03：列表显示具体日期（P1）

验证点：

1. 便签列表卡片能看到具体时间：`昨天 18:20`、`周一 14:30`、`08-01 14:30` 等，不再只有「几天前」。
2. 回收站显示 `删除于 …` 同样带具体时间。
3. 窄窗口下日期不挤压标题和摘要。

证据要求：

- 截图：列表中的具体日期。

### 4. F04：侧边栏折叠/展开（P2）

验证点：

1. 宽屏下侧边栏顶部（搜索旁）有收起按钮。
2. 点击收起 → 列表隐藏，编辑区占满，左侧留一条细展开条。
3. 点击展开条 → 侧边栏恢复。
4. 重启 App 后折叠状态被记住。

证据要求：

- 录屏：收起 → 编辑区占满 → 展开。

### 5. F05：删除确认是产品内 Modal（P1）

验证点：

1. 删除便签 → 弹出产品内确认框（不是浏览器 confirm）。
2. 文案：「确定删除此便签？删除后可在回收站恢复。」按钮：取消 / 删除（红）。
3. 回收站「永久删除」→ 更强文案：「永久删除后无法恢复，确定删除此便签？」
4. 删除图片 → 自定义确认框。
5. Windows 壳内没有「网址显示确认」这类网页穿帮提示。

证据要求：

- 录屏：删除便签弹自定义 Modal。
- 截图：回收站永久删除弹窗。
