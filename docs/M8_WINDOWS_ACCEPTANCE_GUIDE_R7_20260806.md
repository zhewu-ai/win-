## 本轮验收重点（第 7 批）

### 1. 右键菜单分场景（P1）

验证点：

**a. 便签卡（侧边栏列表）右键**：
- 弹出自定义菜单，含两项：`复制一份`、`删除便签`。
- 点 `复制一份`：出现一份新便签，标题为原标题 + 「副本」，内容与图片一致，置于列表顶部。
- 点 `删除便签`：弹出产品内确认框（「删除便签 / 确定删除此便签？删除后可在回收站恢复。/ 取消 / 删除」），确认后便签进入回收站。

**b. 编辑器内容区右键**：
- 弹出文本菜单：复制 / 粘贴 / 剪切 / 全选 / 删除所选。
- **未选中任何文字**时：`剪切`、`删除所选` 为灰色禁用。
- **选中部分文字**后右键：`剪切`、`删除所选` 变为可用。

**c. 空白区域 / 普通非编辑区域右键**：
- 无自定义菜单，**同时不弹出系统默认菜单**（空白安静）。

证据要求：三种场景各录屏/截图一张。

### 2. 回收站自动清理与剩余时间显示（P1）

验证点：

**a. 剩余保留时间**：
1. 删除一条便签，进入回收站。
2. 该便签显示「删除于 8月6日 · **6天后永久删除**」（或按剩余天数显示；当天到期显示「今天将永久删除」）。

**b. 到期自动清理**：
- 已满 7 天的便签会在每日定时（04:07）自动永久删除，无需手动操作。删除后回收站列表消失该条。
- 手动删除测试（可选）：在回收站点「永久删除」，确认框文案含「永久删除后无法恢复」。

证据要求：
- 截图：回收站条目显示「删除于 … · N天后永久删除」。
- 说明：若当天无满 7 天便签，自动清理不会产生可见变化，属正常。

## 常见问题

**Q：回收站里便签显示「删除于 8月6日 · 7天后永久删除」，为什么是 7 天后？**
A：保留期为 7 天，从删除时刻起算。刚删除时显示「7天后永久删除」，次日显示「6天后」，以此类推。

**Q：我右键点了空白处，没反应，是不是坏了？**
A：这是预期行为。按设计，空白区与普通区域不弹任何菜单（含系统默认菜单）。

**Q：复制一份的图片会被复制吗？**
A：会。服务端复制附件文件并新建附件记录，副本可独立查看/删除。

**Q：如果当天机器关机，定时清理会漏吗？**
A：定时任务开启 `Persistent=true`，错过的时间点会在下次开机后补执行。
