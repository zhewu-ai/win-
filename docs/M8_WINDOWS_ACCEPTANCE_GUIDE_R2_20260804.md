## 本轮验收重点（第 2 批）

### 1. F01：待办长文本在小窗口自然换行（P0）

验证点：

1. 新建/打开待办便签，输入一条 80 字以上的中文长句。
2. 悬浮窗缩到约 260px 宽、主窗口缩到约 320px 宽。
3. 待办文字自然换成多行，**不裁切、不出现横向滚动**。
4. 左侧勾选圆圈、拖拽手柄、右侧删除按钮不遮挡文字（右侧删除按钮在悬停时出现，不挤占正文）。

证据要求：

- 截图：260px 悬浮窗、320px 主窗各一张（含超长待办）。
- 说明文字确认换行后无横向滚动条。

### 2. F02：待办小标题 / 统一已完成区（P1）

验证点：

1. 任意两个待办之间插入小标题（行间悬停的"＋"或底部"添加小标题"）。
2. 小标题**没有**圆形勾选框。
3. 小标题可编辑、可删除（悬停出现删除按钮）、可拖拽排序。
4. 小标题下方的待办勾选后进入**统一**的底部"已完成"区（不是每个小标题下面各一个已完成区）。
5. 已完成区可折叠/展开；取消完成后待办回到列表。
6. 旧数据（M6 分组模型）打开后自动迁移成新扁平行，无报错、无丢失。

证据要求：

- 录屏：插入小标题 → 勾选一条待办 → 展开"已完成"区 → 取消完成。
- 拖拽排序录屏一段。

### 3. F03：Tauri ACL 权限——置顶 / 极小模式（P0）

验证点：

1. Windows App 内点「窗口置顶」→ **不再出现 ACL 错误**（`ACL 不允许使用命令 ...` / "请确认在桌面壳中运行"），置顶开关实际生效。
2. 点「极小模式」→ 能打开悬浮窗。
3. 悬浮窗默认置顶，Alt+Tab 切走后仍不被遮挡。
4. 若仍失败：DevTools 控制台贴完整报错文本（本轮新增了 `allow-*` 权限，理论上应通过；若配置仍不生效需贴报错）。

证据要求：

- 录屏：置顶开→关→开；极小模式打开悬浮窗。
- Windows DevTools 控制台截图（无 ACL 报错）。

### 4. F04：时间戳弱化到底部（P2）

验证点：

1. 主编辑页**顶部不再**显示大时间戳。
2. 编辑器**底部**显示弱化的"最后编辑于 …"。
3. 悬浮窗顶部不显示大时间戳。

证据要求：

- 截图：主编辑页顶部（无时间戳）+ 底部（最后编辑于 …）。

### 5. F06：右键菜单位置稳定（P1）

验证点：

1. 连续在不同位置右键 10 次。
2. 菜单**直接**出现在鼠标位置附近。
3. **不出现**"先在旧位置闪一帧再跳到正确位置"。

证据要求：

- 录屏：连续右键不同位置，菜单每次都直接出现在鼠标附近、无闪烁。
