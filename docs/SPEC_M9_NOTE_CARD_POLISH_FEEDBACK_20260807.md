# PinNote M9 左侧便签卡片视觉补充反馈

日期：2026-08-07

## 1. 背景

M9 视觉换皮目前整体方向基本正确，并且这次调整顺带解决了之前横向自适应布局临界点闪动/颤动的问题。这个修复体验很好，请保持当前响应式布局稳定性，不要为了下面的小视觉调整重新引入闪动。

本反馈只针对左侧便签预览卡片的几个视觉细节，不扩大功能范围。

## 2. 本轮只改三件事

1. 左侧卡片颜色标记：从左侧竖条改为右上角圆形色点。
2. 左侧卡片图片预览：如果和右上角色点冲突，优先取消图片缩略图预览。
3. 左侧卡片日期信息：在右下角显示创建日期或最后修改日期，建议优先显示最后修改日期。

## 3. F01：颜色标记从左侧竖条改为右上角圆点

当前体验：

- 左侧便签卡片用左边竖条表示颜色。
- 这个做法偏工具/后台列表感，和 M9 原型里的轻盈卡片感不一致。

产品期望：

- 去掉左侧竖向色条。
- 每张卡片右上角放一个圆形色点，表示便签颜色。
- 圆点应像原型中的小色球，而不是醒目的操作按钮。

建议样式方向：

```text
位置：卡片右上角
尺寸：18-24px 之间，按卡片密度调整
形状：圆形
阴影：轻微内高光/外阴影，可很克制
交互：默认仅作为颜色标识，不需要变成新功能入口
```

注意：

- 右上角色点不要挤压标题。
- 长标题需要给右上角色点预留空间。
- selected 蓝色卡片上，色点仍要能被看见，但不能抢过 selected 主视觉。

## 4. F02：图片缩略图与色点冲突时，取消卡片图片预览

当前顾虑：

- 现在如果便签内有图片，左侧预览卡片右上角可能会显示图片缩略图。
- 如果颜色圆点也放到右上角，两者会冲突。

产品决策：

```text
左侧卡片优先展示颜色圆点；图片缩略图可以取消。
```

原因：

1. 左侧列表的主要任务是快速识别便签，不是浏览图片。
2. 图片缩略图会增加视觉噪音。
3. M9 视觉方向是更干净的便签卡片。
4. 是否有图片不需要在卡片右上角强提示，进入便签后能看到即可。

如果技术部认为必须保留图片存在提示，可以使用非常轻的图标或附件数量提示，但本轮不要求做。

## 5. F03：右下角增加日期

当前体验：

- 左侧卡片目前缺少日期信息。
- 用户希望能在列表里看到这条便签的时间。

要求：

- 在卡片右下角显示日期。
- 建议优先显示最后修改日期。
- 如果当前数据/接口更容易拿创建日期，也可以先显示创建日期，但需要保持口径一致。

推荐口径：

```text
优先：最后修改日期 / 更新时间
备选：创建日期
```

日期格式建议：

```text
今天：今天 HH:mm
昨天：昨天 HH:mm
过去 7 天：周几 HH:mm
更早：MM-DD HH:mm 或 YYYY-MM-DD
```

显示位置：

```text
卡片右下角
```

视觉要求：

- 日期是辅助信息，颜色使用 muted。
- 不要比标题和正文预览更抢眼。
- 日期和待办进度如果同时存在，需要排版清楚，不要重叠。

## 6. 建议卡片结构

建议每张左侧卡片按这个信息层级组织：

```text
┌──────────────────────────────┐
│ 标题                    ●    │
│ 正文/待办预览                 │
│ 正文/待办预览                 │
│                         日期 │
└──────────────────────────────┘
```

如果有待办进度：

```text
┌──────────────────────────────┐
│ 标题                    ●    │
│ ○ 待办预览                   │
│ ✓ 待办预览                   │
│ 2/3                    日期 │
└──────────────────────────────┘
```

这里的 `●` 是便签颜色圆点，不是按钮。

## 7. 不要改的部分

本轮不要动：

1. 已经修好的响应式布局稳定性。
2. 侧边栏自动收起动画。
3. 工具栏响应式策略。
4. 保存、防丢、同步逻辑。
5. 图片上传和附件详情能力。
6. 便签详情页布局。

## 8. 验收标准

通过标准：

1. 左侧卡片不再显示颜色竖条。
2. 每张卡片右上角有圆形颜色标记。
3. 有图片的便签不会因为图片缩略图和色点重叠而显得混乱。
4. 卡片右下角能看到日期。
5. 标题、正文预览、待办进度、日期、色点之间没有重叠。
6. 亮色和暗色下都清楚。
7. selected 状态下仍然好看、可读。
8. 390px/320px 或侧边栏窄宽度下不裁切、不抖动。

不通过标准：

1. 色点压住标题。
2. 图片缩略图和色点同时抢右上角。
3. 日期和待办进度重叠。
4. 卡片重新变成明显后台列表感。
5. 为了这次小改导致响应式闪动问题复发。
