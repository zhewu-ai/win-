# PinNote M10.9 交付报告：桌面应用下载入口 + 左栏选择按钮微调

日期：2026-08-07

## 1. 结论摘要

M10.9 已上线。本轮做了两项很轻的网页端体验修正（SPEC_M10_9）：

1. **桌面应用下载入口**：账号菜单底部（反馈问题与外观之间）新增「下载桌面版」小入口，只在**桌面浏览器网页**显示（`hidden md:flex`），手机端隐藏、Windows Tauri App 内不渲染；链接指向 GitHub Release 页，URL 收敛到 `src/lib/downloads.ts` 单一常量。
2. **左栏选择按钮微调**：左侧列表顶部的「选择」文字大按钮改为**横向三点图标**（heroicons dots-horizontal），热区 28×28px，`title`/`aria-label` 均为「选择便签」；图标与置顶标题之间的垂直空隙从约 30px 收紧到 **8px**。多选删除逻辑未改动。

本地与生产验收全部通过并已上线。

## 3. 功能一：桌面应用下载入口

### 3.1 配置收敛
```ts
// src/lib/downloads.ts
export const DESKTOP_APP_DOWNLOAD_URL =
  "https://github.com/zhewu-ai/win-/releases/tag/v0.1.0";
```
URL 只维护这一处。后续更新 Release 版本时同步改此常量。

### 3.2 展示规则（SPEC §5.2）
| 环境 | 是否显示 | 实现 |
|---|---|---|
| 桌面浏览器 Web | 显示 | `hidden md:flex`（≥768px） |
| 手机浏览器 Web | 隐藏 | `hidden` 生效（元素仍在 DOM，display:none） |
| Windows Tauri App | 不渲染 | `!isTauri()` 条件包裹，DOM 中不存在 |
| 窄窗口桌面浏览器 | 可隐藏 | 同 `md` 断点 |

### 3.3 交互
- 菜单项 `target="_blank"` 新标签打开 Release 页，`rel="noopener noreferrer"`。
- 点击后关闭账号菜单。
- 样式为普通菜单项（小号、非主按钮），不占主操作、不弹窗强推。

## 4. 功能二：左栏选择按钮微调

### 4.1 外观
- 「选择」文字大按钮 → 横向三点图标（heroicons `dots-horizontal`），w-7 h-7（28×28px 热区，满足 ≥28px）。
- 图标颜色 `text-ink-muted`，hover 变 `text-ink` + `bg-surface-hover`，与既有菜单项 hover 反馈一致。
- `title="选择便签"` + `aria-label="选择便签"`（满足 tooltip 口径）。

### 4.2 间距
- 图标行 `pt-1.5 → pt-1`；列表容器 `py-2 → pt-1 pb-2`；置顶 SectionHeader `first:pt-4 → first:pt-1`。
- 实测：图标底部 →「置顶」标题顶的垂直空隙 **8px**（目标约 8px）；图标底部 → 第一张便签卡片顶总距 37px（含置顶标题行）。

### 4.3 交互
- 点击三点图标进入多选模式：显示「已选 X 条 / 全选 / 取消 / 删除」，每条便签出现勾选圆圈。
- 取消后回到三点图标，不保留选中状态。多选删除逻辑未改动。

1. **Release 链接**：本机对 github.com 网页域名网络受限，已用 GitHub API 验证 release 与资产完整（§5.3）；github.com 网页 200 与浏览器内实际加载，建议在 Windows/浏览器实机验收时点一次确认。

3. 后续更新 Release 版本时，需同步修改 `src/lib/downloads.ts` 的 `DESKTOP_APP_DOWNLOAD_URL`，并在本交付报告口径上更新推荐安装包文件名。
4. 左栏间距收紧只调整了 padding 与 `first:` 规则，不影响便签卡片视觉样式与多选删除逻辑。
